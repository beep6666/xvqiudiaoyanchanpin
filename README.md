# 见微 · 货盘组现场研究助手 V0.1

帮助观察者专注真实工作：现场用一句话捕捉事实，事后引用原始记录还原任务，保留未知与待验证的假设。

React + TypeScript + Vite，纯前端，无登录、后端、云数据库或外部 AI 服务。业务数据只写入当前浏览器的 localStorage，不随源码提交到 GitHub。

## 本机启动

需要 Node.js **20.19+ 或 22.12+**（已在 Node.js 24.18 上验证）。首次安装依赖需要联网，此后运行应用不需要联网。

```powershell
git clone https://github.com/beep6666/xvqiudiaoyanchanpin.git
cd xvqiudiaoyanchanpin
npm ci
npm run dev
```

打开 **http://127.0.0.1:5173/**。Windows 也可以双击 `启动助手.cmd`，自动检查依赖、启动服务并打开浏览器。保留命令窗口；结束后按 Ctrl+C。

当前工作区已经安装依赖，可在本目录直接执行 `npm run dev`。

**请始终使用同一设备、同一浏览器和相同访问地址。** `localhost`、`127.0.0.1`、不同端口和不同浏览器使用各自的存储空间。不要直接双击 `index.html`。数据存储在当前设备的浏览器中，清理浏览器数据、退出私密浏览或更换访问地址都可能使记录不可见或丢失，请及时导出 JSON 备份。

## 第一次使用（现场）

1. 默认进入「现场快速记录」。点「快速新建」填一个任务名；也可直接输入并保存，自动建立“未命名现场任务”。
2. 写一句刚看到或听到的内容，选择「直接观察 / 对方原话 / 我的疑问 / 我的推测」，点保存或按 **Ctrl+Enter / Cmd+Enter**。保存后正文清空、任务保留、输入框继续聚焦。
3. 不知道目的、耗时或系统名称时直接留空。「补充细节」默认折叠。重要记录点星标，需要时再编辑。
4. 当天结束前，点左下「数据备份与恢复」→「导出 JSON」。备份文件可能包含企业信息，请保存在自己的合适位置。

「今日指南」包含研究目标、可调整的时间安排、六个重点、研究原则和按需展开的追问。工具不要求你现场判断根因或设计方案。

## 事后复盘

「任务复盘」选择同一任务，可以跨日期继续补充：

- **任务链路**：手工填写七个节点，引用同任务原始记录、补充证据，分别标记待确认/已确认。修改立即保存；缺失环节保持未知。
- **候选问题**：手工区分已确认事实、原因假设、未知信息和下一步验证方法，关联证据。最多三个问题选入报告。核对状态由用户维护，系统不会把假设自动变成根因。
- **研究报告**：七段 Markdown，根据已存数据确定性整理。报告范围明确为本机全部已存记录；代表性链路与候选问题针对当前任务。事实摘要最多8条、疑问/推测摘要最多6条，完整原始档案保留于 JSON。支持复制和下载 `.md`。

任务没有结束，或结果尚未完整确认时，报告明确保留“尚未观察到后续结果”。保存时间只用于定位记录，不用来推算工作耗时、全组效率或 ROI。

## 备份、恢复与可靠性

- JSON 包含 Case、Note、Finding、任务链、确认状态、证据与稳定 ID 引用关系。
- 导入前验证版本、字段、日期、唯一 ID、任务归属和记录引用，拒绝损坏文件或悬空/跨任务引用。文件上限10 MiB。
- 检查通过后才显示「确认替换并恢复」，恢复会**替换**现有数据，不合并。请先手动导出当前数据。恢复前还会在本机保留最近一次安全副本，可在同一弹窗下载。
- 编辑内容/任务名保留 ID。删除记录会同步移除引用；移动记录到另一任务时移除原任务引用并保留记录 ID。删除任务会删除该任务全部记录、问题和链路。删除均需要明确确认。
- 输入中的快速记录草稿也会保存在本机。存储失败时不清空输入；多个窗口并行修改时暂停旧窗口写入，避免覆盖，保留草稿并提示刷新。
- 快速记录草稿按窗口隔离。复盘链路保存失败时另存当前标签页会话草稿，显示未保存提示，可重试或导出含草稿的 JSON；报告始终只使用已保存内容。如果会话存储也不可用，会明确提示先复制或导出、不要刷新。
- 本地数据无法解析时暂停写入，可下载原始数据再恢复，不会悄悄覆盖为空数据。
- 浏览器本地存储容量有限；JSON备份不能替代设备安全措施。不支持多人同步、自动云端备份或跨浏览器自动迁移。

真实浏览器验收脚本、覆盖范围和实测结果见 [TESTING.md](TESTING.md)。浏览器脚本需要 Playwright 与 Chrome；它们只用于开发验收，不是运行工具的前提。

## 范围与边界

P0：今日指南、连续快速记录、任务管理、编辑删除、重要标记、本地持久化、任务链引用、候选问题、JSON 备份恢复、复制与导出 Markdown 已实现。

额外提供轻量搜索与筛选。未实现计时器、活动统计、多用户/多设备同步、公网部署和录音/录屏。已验证桌面 Chrome 及手机视口模拟；未在真实线下观察、实体手机、Safari 或所有浏览器版本上验证。自动化脚本的操作耗时不等于真人首次理解或现场记录耗时。
